3) gpcopy 테스트 (테이블)

#Coordinator(마스터) 경유 전송 (양방향 성공)
  gpcopy --source-host 172.16.200.161 --source-port 5432 --source-user gpadmin \
    --dest-host 172.16.200.191 --dest-port 5432 --dest-user gpadmin \
    --include-table kbc.public.production_lot --truncate \
    --on-segment-threshold -2

  gpcopy --source-host 172.16.200.191 --source-port 5432 --source-user gpadmin \
    --dest-host 172.16.200.161 --dest-port 5432 --dest-user gpadmin \
    --include-table kbc.public.production_lot --truncate \
    --on-segment-threshold -2

#Coordinator(마스터) 비 경유 전송 (세그먼트 간 직접 전송, 양방향 성공) 
  gpcopy --source-host 172.16.200.161 --source-port 5432 --source-user gpadmin \
    --dest-host 172.16.200.191 --dest-port 5432 --dest-user gpadmin \
    --dest-mapping-file /home/gpadmin/dest_hosts.map \
    --include-table kbc.public.production_lot --truncate 

  gpcopy --source-host 172.16.200.191 --source-port 5432 --source-user gpadmin \
    --dest-host 172.16.200.161 --dest-port 5432 --dest-user gpadmin \
    --dest-mapping-file /home/gpadmin/dest_hosts.map \
    --include-table kbc.public.production_lot --truncate 

참고 : 
이슈1) [ERROR]:-dialing to 127.0.0.1:36161 time out: dial tcp 127.0.0.1:36161: connect: connection refused 발생
--dest-mapping-file 옵션을 사용하여 맵핑 파일을 생성 후 사용
