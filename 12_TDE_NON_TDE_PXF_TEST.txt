테스트 목적 : TDE 가 적용되지 않은 데이터베이스에서 생성한 s3 외부 테이블을 TDE 가 적용된 데이터베이스에서 읽기/쓰기가 가능한지 확인

테스트 환경 : 
v6 (Non-TDE)	: DB- 6.32.1  , PXF version 6.7.0  
v7 (TDE) 		: DB- 7.7.1   , PXF version 8.0.3

테스트 시나리오 : S3(MinIO)를 통한 s3:parquet, s3:text 테스트

테스트 결과
1. v6에서 생성한 외부테이블 v7 TDE에서 읽기/ 쓰기 결과 : 성공
2. v7 (TDE 적용)에서 생성한 외부테이블을 v6에서 읽기/ 쓰기 결과 : 성공

발생시

환경 변수로 $PXF_BASE 설정해도 문제 발생

#해결방법
아래와 같이 명령서 실행시 셋팅하여 각 단계 실행
PXF_BASE=/usr/local/pxf-gp7 pxf cluster prepare
PXF_BASE=/usr/local/pxf-gp7 pxf cluster register
PXF_BASE=/usr/local/pxf-gp7 pxf cluster sync
pxf cluster restart 이후 문제 발생하지 않음
