-- ANALYZE가 수행된 지 24시간이 지났거나, 단 한 번도 수행되지 않은(NULL) 테이블을 찾는 SQL 쿼리

SELECT 
    n.nspname AS schema_name,
    c.relname AS table_name,
    COALESCE(TO_CHAR(stat.last_analyze_time, 'YYYY-MM-DD HH24:MI:SS'), 'NEVER') AS last_analyze
FROM 
    pg_class c
JOIN 
    pg_namespace n ON n.oid = c.relnamespace
LEFT JOIN 
    (
        SELECT objid, MAX(statime) AS last_analyze_time
        FROM pg_stat_last_operation
        WHERE staactionname = 'ANALYZE'
        GROUP BY objid
    ) stat ON c.oid = stat.objid
WHERE 
    c.relkind = 'r'                                                         -- 일반 테이블만 조회
    AND n.nspname NOT IN ('pg_catalog', 'information_schema', 'gp_toolkit') -- 시스템 스키마 제외
    AND n.nspname NOT LIKE 'pg_temp%'                                      -- 임시 스키마 제외
    AND (
        stat.last_analyze_time IS NULL                                      -- 한 번도 안 한 경우
        OR stat.last_analyze_time < NOW() - INTERVAL '24 hours'             -- 마지막 수행 후 24시간 경과
    )
ORDER BY 
    stat.last_analyze_time ASC NULLS FIRST, 
    schema_name, table_name;
